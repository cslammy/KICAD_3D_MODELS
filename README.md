GETTING IT TO WORK WITH YOUR KICAD SETUP:     
--The zip file has my most recent renditions of the models. Copy it to your HD and unzip it. \
--In Kicad, create a custom configuration path ${CLOUD_DIR_3D}   \
--Point this to where you unzipped the 3D files   \
--3D files are folderized (POTS, SWITCHES, JACKS etc.) vs. a ton of files all over the place.
